# ai-rea

用 AI 做逆向的工作区。底层工具是 [REA](https://github.com/morluto/rea)，以命令行方式调用，
不注册 MCP、不改动你其他客户端的配置。

---

## 这个项目能帮我做什么

把「一个能运行但不完全透明的程序」变成「一份能读懂、能照着重建的说明书」。

| 拿什么喂它 | 能得到什么 | 现在能不能做 |
|---|---|---|
| 打包后的网页 / Electron 应用 | 模块结构、依赖图、接口、资源清单、业务逻辑还原 | ✅ 立即可用 |
| .NET 程序集 | 类型、方法签名、字符串、P/Invoke 边界 | ✅ 立即可用 |
| APK | 包结构、manifest、签名、资源；IL2CPP 符号清单 | ✅ 结构与符号（反编译需装 JADX） |
| 原生 exe / dll | 函数伪代码、调用关系、导入导出表 | ⚠️ 需要装 Ghidra（Windows 上仅 x64 PE，实验性） |
| 固件 / 抓包 / 进程内存 | — | ❌ Windows 不支持 |

**最适合的场景**：你手上只有发布产物（`dist`、`asar`、`apk`），没有源码，
想知道里面怎么算的。若已有源码，直接读源码更快，不必绕这一圈。

### 关于「复刻游戏」

能帮的是**逻辑层**：数值公式、状态机、刷新规则、存档格式、数据结构。
帮不上的是**内容层**：美术、动画、音效、手感参数 —— 那些要靠 AssetStudio、AssetRipper 之类的专用工具，
且涉及版权，不在这个工作区范围内。

## 怎么开始

第一次使用，在项目目录下执行三条：

```powershell
nvm use 24.22.3      # 切 Node 版本（本机用 nvm 管理，必须先切）
pnpm install         # 装依赖，只需一次
pnpm exec rea doctor --json
```

`doctor` 报 `missing_analysis_engine` 是正常的 —— 只是没装反编译引擎，不影响网页/.NET 分析。

## 怎么向 AI 提需求

逆向最容易失败的地方不是工具，是**问题不具体**。按这四行说，能省掉大半轮次。

```
目标：<路径或名字>
想问：<1~3 个具体问题>
产出：<报告 / 对照表 / 可运行代码 / JSON>
边界：<能不能运行它？能不能联网？能不能装工具？>
```

### 例子

**最小可用**

```
目标：targets\mech-ruins-dist
想问：敌人波次是怎么生成的
产出：伪代码 + 中文解释
边界：只读，别装东西
```

**标准版**

```
目标：targets\mech-ruins-dist
背景：Vite 生产包，1.7 MB，无 sourcemap，Phaser 4
想问：
  1. 玩家伤害公式是什么
  2. 敌人波次刷新规则
  3. 存档写在哪
产出：每个问题给一段还原后的代码 + 证据位置
边界：只读；结果写 out\mech-ruins\
```

**还不知道想看什么时**

```
目标：<路径>
我不知道该看什么，先给一个概览，再列 3 个最值得深入的点，我来选
边界：只读
```

### 好问题长什么样

| ❌ 太泛，问了也白问 | ✅ 具体，能被一段代码回答 |
|---|---|
| 看看这个游戏怎么做的 | 敌人移动是朝玩家直线追，还是有寻路？ |
| 分析一下这个 exe | 启动时读了哪些配置文件，路径怎么拼的？ |
| 有没有加密 | 请求 body 是明文还是加密？密钥从哪来？ |
| 能不能复刻 | 核心战斗循环需要哪几个数据结构？给字段定义 |

原则：**能被一个「是/否」或「一段代码」回答的问题，才是好问题。**

## 文件放哪，结果在哪

| 位置 | 放什么 | 会不会进 git |
|---|---|---|
| `targets\<项目名>\` | 待分析的样本，复制进来，不要移动原文件 | 不会 |
| `out\<项目名>\` | 分析结论、反编译产物、导出的证据 | 不会 |
| `notes\` | 值得长期保留的结论、环境记录 | 会 |

## 授权

默认按「只读 + 可写工作区」执行：能读文件、能在 `targets\` 和 `out\` 里生成文件，不联网。

超出这个范围的任何动作，AI 都必须先停下来说明再等你同意：

| 档位 | 需要你同意的内容 |
|---|---|
| 可运行目标 | 启动程序 / 网页，观察运行时行为 |
| 可联网 | 抓包、访问线上站点 |
| 可装工具 | 安装 JADX / Ghidra 等引擎（会先报体积、装到哪、有什么副作用） |

**装任何东西（包括 `pnpm add`、升级 REA、下载工具）都会先问你，不会默认执行。**

## 常见问题

**为什么不用 Claude Code 插件里那个 REA？**
插件会往你的全局配置里注册 MCP server，还和项目内的 skill 重复。这里用 CLI 直调，干净、可回滚。

**为什么不全局安装？**
全局安装会跟着 Node 版本走，切一次版本就失效。项目内安装锁了版本，换机器 `pnpm install` 就恢复。

**REA 升级会不会破坏现有用法？**
不会自动升级。要升级时我会先说明改了什么，你同意后再动。

**能不能直接帮我改/发布游戏？**
这个工作区只做分析，产出都是报告和代码片段。重建工作在别的项目里做。
